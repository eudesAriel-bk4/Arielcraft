o Arielcraft é uma Versão do Minecraft java feita por Arielgameplay. Porém

1. é uma versão Modificada mas foi Testada, é Segura TOTAL e não travou
2. o Ariel Pack será Instalado ao Aplicativo.jar
3. Mods serão Instalados no Arielcraft por Recursos Precisos no Arielcraft

Como Instalar o ArielCraft no Launcher Minecraft

1. Vá no Diretório do Minecraft Java
2. mova o ArielCraft para a Pasta "versions" do Diretório
3. Abra o Minecraft Launcher
4. Clique em Minecraft Java Edition
5. Vá em Instalações
6. Vá em Nova Instalação
7. clique em Diretório do Jogo e vá em Buscar
8. Substitua o diretório atual(se não for do Minecraft) por "C:\Usuários\seu Usuário\Appdata\Roaming\.minecraft\versions\arielcraft-1.0-snapshot-{number}"
9. em "Versão", Escolha: release fabric-loader-0.19.3-26.2 (se Não tiver o fabric instalado, instale em https://fabricmc.net/use/installer/ e a versão Escolha a versão atual 26.2)
10. clique em "Iniciar após a Instalação" e Depois em Instalar
11. - Opcional: coloque o Nome da Instalação/jogo

Como Instalar o Arielcraft no Seu Computador

1. vá em https://github.com/eudesAriel-bk4/Arielcraft/releases
2. Escolha a Versão do Arielcraft
3. Escolha o Arquivo .zip da Release ou Pre-Release
4. Extraia o .zip e Instale no seu Launcher
